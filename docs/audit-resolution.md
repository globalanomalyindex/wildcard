# Audit resolution ledger

Dated 20 September 2026. This ledger tracks the 41 findings in the supplied audit against the corrected product and the new historical evidence audit. It does not declare that every acceptance criterion has passed or that every historical observation has been repaired.

**Implemented** means the named code or documentation change is present. Remaining verification is stated in the row; it is not implied by that label. **Evidence limitation** means the underlying historical uncertainty remains and is reported. **Proposed** means further work is specified but not claimed complete. Several findings need more than one label because a reporting correction cannot repair missing data or prove a behavioral guarantee.

Source references: [historical evidence audit](../research/audit-2026-09/README.md), [sampler v2 contract](sampler-v2.md), [methods colophon](methods-colophon.md), [next-study protocol](../research/transfer-v1/protocol.md). Historical `experiment/` artifacts and analyzers remain frozen; new validation and sensitivities live under `research/`.
