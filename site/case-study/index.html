          a testable question, not a neural metaphor

          hold the relation.
          change the name.

          random cue injection has prior art. the narrower contribution is a donor-name intervention with explicit transfer boundaries and a baseline-relative mechanism measure.

          what is controlled

          every main condition gets the same brief and the same allowance: up to four actions, each no more than 110 words. R, LR, and XR receive the exact same relation and boundary. only the explicit domain name changes.

          the four prompt conditions
          conditionoutside information
          Sstrong direct prompt, no cue
          Rrelation + boundary
          LRsame relation + correct name
          XRsame relation + mismatched name

          this matches output allowance, not total tokens. actual usage and latency are recorded.

          what gets counted

          a mechanism must respect the brief's constraints, be judged feasible, and describe an executable action with an observable check. duplicate mechanisms count once. when any candidate in a judge’s mechanism group matches the bank, every copy of that group is treated as non-new for that brief.

          QNM@4 adds one more condition: the mechanism is absent from two separately generated baseline responses for that brief. the bank is never shown to the main generator.

          two masked judge configurations evaluate the actions. their scores are averaged within each brief. the brief is the analysis unit; judge votes do not increase the sample size.

          what this cannot establish

          these are authored synthetic briefs and model judgments. a relation can reveal its source even when unnamed. absence from a finite bank is not world originality. a feasible-looking proposal is not a shipped result.

          the requested generator is gpt-6-astra; judges request gpt-6-astra and gpt-5.5. provider-returned snapshots are not exposed by the Codex CLI transport and are recorded as unknown.

          separate counterfactual fixtures check relation following and boundary handling. they are not proof of creativity or the cause of any main-study effect.

          prior art & contribution boundaries ↗

          a measurement failure, kept in the record.

          one of the original 64 judge blocks used candidate IDs where bank references were required. the frozen protocol halted the primary analysis. all 64 blocks were then remeasured under a published amendment, with reference IDs constrained to the correct bank. generated ideas, prompts and scoring stayed fixed; the two panels were not pooled.

          the result reported here is an amended measurement on the same generated sample, not a completed original primary test or an independent replication.

          failure, amendment & frozen rules ↗
          inspect the separate counterfactual checks

          each pair changes an operational relation while keeping its invented donor label fixed. these are exact-output checks of relation following and boundary handling, not creativity scores. read the expected and observed traces before interpreting a failure.
