## angles
- Three kinds of pressure (subscription, elderly relatives, messy notes) carried as equally urgent, but subscription is a two-way door (data doesn't vanish, can resubscribe) while relatives who could identify faces is a one-way door (once gone, irreversible) -> door-type should set order of operations, not calendar -> spend this month's attention on the irreversible thing (photo-ID session with relatives, even informal or phone-recorded), and solve the subscription less elegantly, or later, or by exporting what you need before it lapses

- Birth-year conflict is a provenance problem (two claims with no record of which evidence backs which), not a research problem; forensic and museum practice records source with each fact so conflicts become visible instead of silently merging -> need to track which evidence backs which claim to stop losing the ability to tell -> before doing new research, tag each disputed fact with its source; may not resolve which year is correct but make conflicts traceable

- Two trees that disagree is structurally identical to two branches of code that diverged and need merging; software doesn't pick one and discard but looks at diff line by line and keeps provenance for each choice -> instead of reconciling two GEDCOMs into one "true" tree, treat them as separate branches -> do field-by-field diff and note both values and which source supports each, rather than silently overwriting one with the other

- Identification and preservation treated as one step, but reporters interviewing sources under time pressure split into two separate acts (record raw first, fact-check afterward) because capture window and verification window close at different speeds -> these windows operate on different timescales -> sit with relative and get them talking over photos (recorded) without pausing to cross-check dates or spell names; messy transcript is far more recoverable later than a lost afternoon trying to get everything precisely right the first time
