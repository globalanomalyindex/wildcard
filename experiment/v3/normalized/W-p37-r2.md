## angles
- Persistent ID binding collapses multiple reference systems into one authoritative lookup -> invoices, manifests, labels, and speech create four separate naming paths for the same lot, all requiring hand-built crosswalks after the fact -> stamp one lot ID format (supplier code + landing date + sequence) on pallet at dock and carry through box label, invoice, and manifest
- Interval records answer the temporal questions asked later more than single timestamps do -> your three excursions show only whether they crossed the 40°F threshold, not duration or stage of the morning sort -> log two timestamps and two temperature readings per batch at dock (moment of arrival and moment of departure for cooler or van)
- Stamped dates judge automatically without eyeballing -> freshness assessment currently depends on someone in the cooler judging by sight -> timestamp on lot ID auto-triggers day-two markdown and routes anything past cutoff to the fish-market channel without manual judgment
