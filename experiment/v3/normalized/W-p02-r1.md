## angles
- Amebocyte clotting speed in open-circuit systems with no valve isolation means one wound can drain the whole organism -> Webhook outage: one misconfigured gate with no isolation in control-plane path blocked all cluster scheduling -> Scope admission webhooks with namespaceSelector/objectSelector, set failurePolicy: Ignore on non-critical, keep timeoutSeconds 1-2s, run drill with deliberately broken webhook to verify recovery time in seconds
- Bleeding capacity isn't budgeted by calendar but by recovery signal (hemolymph and amebocyte counts restored) -> Node replacement scheduled by fixed time interval instead of service-specific recovery signal -> Define explicit resync-complete signal per stateful service (replica lag at zero, custom readiness probe) and gate next node replacement on signal firing, not time
- Actual field solution removed live extraction via recombinant Factor C (synthetic reagent) rather than improving extraction technique -> Pinned local storage creates recurring node-replacement hazard on every future upgrade, not a one-time cost -> Migrate 2-3 highest-risk stateful services to networked storage (EBS CSI, EFS) one time, rather than re-choreographing replacements every cycle
