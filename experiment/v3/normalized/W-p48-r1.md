## angles
- Long-lead infrastructure must be ordered long before the window opens, because installation takes longer than the window lasts — you can't respond to it, you must already be ready → Your ISP is that pipe: a 3-week backlog that doesn't care when your 6-day move window opens → Place the order now, 5 weeks out, to land 2 weeks ahead; ask now about a loaner hotspot if the install date still lands on or after move-in
- Don't spend the event fussing over low-slack secondary lines while the zero-slack line backs up → Your ~40 accounts can be updated any week; electric, internet, and your in-transit passport are truly date-locked → Split into date-locked and slack; clear date-locked first; use USPS mail forward filed at old address to redirect the passport, not an address update
- Arrays that work don't require a person present at inconvenient hours; use design instead → Offices keep 9-to-6 hours, so calls compete with your work time → Check for web forms first (USPS forwarding, DMV, voter registration, utilities); save phone time for locking the ISP's install date
