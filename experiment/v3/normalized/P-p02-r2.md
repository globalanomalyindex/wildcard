## angles
- "Ten weeks" treated as hard deadline -> May be a price, not a wall -> Price out AWS EKS Extended Support as a call option to decouple "must upgrade" from "safe to upgrade" before compressing the migration into a constrained window
- Airlines use Minimum Equipment List + pre-flight checklist for non-critical broken systems -> Deprecated-API workloads need explicit tracked waivers instead of implicit vague risk -> Create a dated waiver list per team; implement mandatory pre-flight checklist before cluster changes to catch admission-webhook-type failures
- Bridge engineers build temporary parallel structure before replacing load-bearing bridge under live load -> No staging cluster argues for parallel cluster, not for accepting risky in-place surgery -> Build new cluster on target version alongside the old one, then cut over and decommission; converts live surgery into build-new, cut-over, decommission
- Ring vaccination contains outbreaks; Incident Command System coordinates scarce responders under time pressure -> Eight teams, low spare capacity, one shared deadline need containment and unified command structure -> Upgrade in deliberately small blast-radius-limited rings; adopt Incident Command System role structure (incident commander, explicit resource requests, pull-based task assignment)
