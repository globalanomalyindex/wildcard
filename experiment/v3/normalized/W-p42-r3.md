## angles
- Switch control routed exclusively through Pi and Node-RED vanishes entirely when that context fails -> mirrors how puppies lose trained responses when context shifts -> set up Zigbee binding so switch drives bulb directly at network layer, eliminating the single point of failure
- Good groundwork not captured immediately gets lost once the window closes, and you're already down to half your flows with corrupted understanding that can't be regenerated -> undocumented work vanishes permanently -> export all flows to file, git init a repo, commit, and write one sentence per flow describing purpose
- Long unstructured sessions trying to cover everything in one sitting burn out without landing anything durable -> one four-hour push collapses into ineffective coverage -> split into two bounded reps: weekend one (Zigbee bind and flows export/commit only), weekend two (isolate and debug one flow alone)
