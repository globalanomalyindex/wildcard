## angles
- Evidence chains designed to be forged shouldn't carry load-bearing signals; load must ride on un-gameable channels (genotype, not manifest) -> Wall switch control currently rides on the fragile SD card + Node-RED layer; when it fails, manual control fails because it was never truly independent -> Use Zigbee direct binding to connect the bedroom switch straight to the bulbs at radio level, skipping the coordinator; test with Pi powered off to confirm the switch still controls lights

- Continuous evidence capture catches degradation early; periodic snapshots taken years apart miss months of undocumented drift -> One-year-old disk image is a periodic snapshot of a constantly-changing system, leaving extended periods unrecorded -> Enable Node-RED Projects feature for passive git commits on flow saves (five minutes setup), then add one weekly cron job to image the SD card to a USB drive or NAS

- Unlabeled samples don't get guessed origins; they get tested against reference instead. Unfamiliar work shouldn't be reconstructed from memory; it should be instrumented. -> When a flow feels like a stranger's work, the urge to reconstruct its intent from memory prevents seeing actual behavior -> Drop Node-RED debug nodes onto the input and output of one suspect flow at a time and run for a day of normal household use; build a running one-page table (flow name / trigger / action / confidence level) as you go
