## angles
- Physical wall switch now depends on smart hub for operation -> Commercial aircraft/elevators solve via independent fallback mechanisms; safety-critical path should not depend on smart path -> Rewire so switch talks directly to bulbs/relay with automation as a layer on top, not the only path
- Pi treated like a pet needing resuscitation from memory -> Infrastructure teams solve corruption by making servers disposable (reflash in 15 minutes, not reconstruct from memory) -> Boot from USB SSD instead of SD; keep provisioning steps in text file/repo so rebuild is mechanical, not a memory test
- Two years of maintenance means you're now inheriting someone else's undocumented code, not authoring it -> Software teams use incremental archaeology on inherited codebases rather than big-bang re-learning -> Export flows as JSON to version control; annotate nodes only when something breaks and requires touching them; documentation accretes exactly where fragility lives
- "Fix the whole system" is an endless four-hour-a-weekend project; "wall switch always works" is a one-sentence promise you can keep -> Ops teams write service agreements that separate non-negotiable requirements from degradable best-effort systems -> Define bedroom lights/wall switch as non-negotiable; everything else best-effort; this framing alone addresses both the technical and relationship problems
