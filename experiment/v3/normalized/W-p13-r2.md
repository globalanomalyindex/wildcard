## angles
- Trained fluency comes from repetition of exact stroke-patterns, not simplification; veterans pattern-match row-shapes while new dispatchers decode character-by-character -> new dispatcher ramp time isn't solved through layout changes but through direct pattern-recognition training -> build a standalone drill tool isolating 5-10 exception patterns, quiz new hires on recognizing them fast out of context like flashcard drills, to measure if it cuts the three-month ramp.

- Dense manuscript pages stayed navigable through rubrication (a second low-resolution channel independent of text), readable at a glance without parsing letters; roomier layout prototypes fail because they change the layer veterans trained on -> hierarchy doesn't require enlarging text but adding an independent secondary channel that doesn't compete with the existing layer -> add a narrow strip per row outside the 18 columns with 4-6 color or shape states for exceptions, leaving the 11px table untouched, and A/B test against current color-in-cells encoding for both novice ramp and veteran scan speed.

- Different readers received different hands from the same source text (textura for slow altar reading, chancery cursive for fast professional work); offering a roomy version as a toggle to veterans' tool asks one hand to serve two opposite purposes -> sales-demo terror and onboarding slog aren't UI problems on the dispatch screen, they're a wrong-hand problem -> build the large-type low-density version as a genuinely separate artifact capped at 15-20 loads with its own column set, use only for sales demos and week-one onboarding, never offered to veterans as a toggle.
