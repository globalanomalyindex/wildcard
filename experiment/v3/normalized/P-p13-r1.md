## angles
- Expert tools (ATC, Bloomberg) don't simplify for beginners; they separate training surfaces from live tools -> treating "months to fluency" as a design failure rather than normal expert-tool curve -> build dedicated training/ramp surface with progressive column reveal and guided drills, not the live dispatch view
- Chess masters pattern-match row shapes instantly; veterans likely pattern-match for exceptions too -> bottleneck is pattern recognition, not column count; hiding columns breaks their scan -> make exception-patterns pre-attentive via color bands, glyphs, sparklines, or shape cues to teach pattern recognition faster
- Competitive games make HUD complexity a saved personal profile, not one global layout -> reframes "roomier vs. revolt" from binary redesign fight into settings problem -> make column set/type size a saved per-dispatcher preset with built-in tiers (new-hire, standard, veteran-dense)
- Enterprise software shows different layouts of same data by role; car dealers differentiate showroom model from delivery -> solves demo-terrifying-small-fleets problem without changing veteran-approved screen -> build curated "starter" preset for demos, distinct from enterprise accounts' actual dense configuration
