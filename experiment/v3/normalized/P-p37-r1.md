## angles
- Hospitals use triage protocol (severity tag and route, not simultaneous sort) for patients from multiple sources with time constraints -> current dock does unload, identify, sort, stage simultaneously, causing product idle above 40°F -> physically split dock into 90-second intake-and-tag zone (cold-holding only) and separate sort-and-route zone downstream
- Wine and cannabis industries use pre-printed stickers (lot number + timestamp at arrival) for lot tracing rather than software -> chef-rejection problem is "lot ID doesn't exist as physical object on the box," not a software problem -> use $30 label printer at point of unload for lot + supplier + landing time
- Airlines and event ticketing use dynamic markdown curves starting when risk becomes visible, not after loss is realized -> day-two discounted fish treated as write-off on fixed day rather than pricing signal -> push automatic discount to price-sensitive restaurants mid-morning before deadline, not at it
- Restaurant kitchens use wireless temp loggers for compliance, which doubles as free operational data -> "prove compliance" and "find where dock is failing" treated as separate problems -> place cheap Bluetooth loggers on dock itself for both inspector paper trail and exact window of daily temperature excursions
