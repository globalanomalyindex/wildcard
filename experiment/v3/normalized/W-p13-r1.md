## angles
- Chalcedony cutting has a hard resolution floor; wisdom is to rank by importance (gods full detail, filler cheap/schematic) rather than render everything equally -> all 18 columns at 11px fidelity is the equal-weight mistake -> rank by veteran exception-spotting usage; give top 4-6 full-fidelity text at 13-14px; convert remaining 12-14 to compact glyphs (color chips, codes, sparklines); reclaimed width funds legibility on priority columns
- Same seal serves two functions by application method (formal full roll, routine partial rolls), not by recut -> one dense table cannot be both dispatcher's daily tool and sales demo material simultaneously -> build separate demo preset (15-20 curated loads, 5-7 clearest columns, larger type, no scroll) for sales; keep operational table at full density for trained users
- Even complex seals carry one plain-language fixed inscription (owner's name/title) so anyone can read that cold and get true signal -> each row needs a plain-language anchor for immediate legibility -> add one anchor column (single word: ON TIME, LATE, AT RISK) in full size, same position on every row; new users get real signal from that one column while trained users read the remaining 17 dense/coded columns
