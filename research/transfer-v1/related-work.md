# Prior work and the scope of this contribution

Primary sources checked on 20 September 2026. This is a targeted review, not an exhaustive proof of priority. Public project attribution: **christopher robin fiore**.

Wildcard's new study asks whether an **explicit donor name adds bank-relative qualified mechanisms once the donor's relation and transfer limit are already present**. The source-backed cue library, controlled name manipulation, finite baseline bank, and auditable product-task evaluation define the contribution. None of random prompting, analogical context construction, semantic-distance selection, or quality-plus-diversity evaluation is new on its own.

| Source | What is already established or proposed there | What this study can add |
|---|---|---|
| [Gentner, Structure-Mapping, 1983](https://onlinelibrary.wiley.com/doi/abs/10.1207/s15516709cog0702_3) | Relational structure is central to a theoretical account of analogy. | A measured prompt-component question; not a claim to invent relational mapping or verify cognitive theory. |
| [Cox et al., Directed Diversity, 2021](https://arxiv.org/abs/2101.06030) | Embedding-distance prompt selection for collective human ideation. | A different fixed-representation intervention; no novelty claim for future embedding routing. |
| [Yasunaga et al., Large Language Models as Analogical Reasoners, ICLR 2024](https://arxiv.org/abs/2310.01714) | Generates relevant exemplars/knowledge before solving reasoning tasks. | Explicit-name ablation with a held-fixed supplied relation on open-ended constrained actions. |
| [Associative Creativity Sparker, 2024](https://link.springer.com/article/10.3758/s13428-024-02463-8) | Word recommendations relative to prior human ideas and the target object can change ideation. | An LLM candidate-action benchmark; no extrapolation to human cognition or long-term creativity. |
| [Mahmoud, Creative Thought Embeddings, 2025](https://ojs.aaai.org/index.php/AAAI-SS/article/download/36064/38219) | Associative cues followed by synthesis/filtering, with prompt-based and proposed model-integrated formulations. | An isolated behavioral comparison. This repository does not implement an activation adapter. |
| [Zhang et al., NoveltyBench, 2025](https://arxiv.org/abs/2504.05228) | Evaluation of multiple distinct high-quality responses, including regeneration strategies. | A task-specific qualification and mechanism-equivalence rubric tied to a frozen baseline bank. A new acronym alone is not the contribution. |
| [Agrawal & Goyal, Addressing LLM Diversity by Infusing Random Concepts, January 2026](https://arxiv.org/abs/2601.18053) | Unrelated random words/sentences change diversity in list-answer experiments. | Constrained actionable mechanisms and the marginal effect of naming the cue's source. Random concept injection itself is direct prior art. |
| [Luo et al., Inducing Sustained Creativity and Diversity, March 2026, v2](https://arxiv.org/html/2603.19519v2) | Random priming phrases and sentence-level token diversions support sustained exploratory generation. | A short one-shot component test with different controls and resource accounting; no claim to surpass sustained search. |
| [Lu et al., Rethinking Creativity Evaluation, EACL 2026](https://aclanthology.org/2026.eacl-long.297/) | Creativity metrics can disagree across tasks and respond to superficial changes. | Granular qualification, explicit equivalence judgments, judge disagreement, and bounded outcome language. Model ratings still need external validation. |
| [Jiang & Merlo, Analogical Structure, Minimal Contextual Cues and Contrastive Distractors, EACL 2026](https://aclanthology.org/2026.eacl-long.22/) | Input-organization ablations for linguistic rule induction. | A different task and intervention. Component ablation and counterfactual input tests are established methods. |
| [Zhang, Xin & Zhong, Where You Inject Diversity Matters, June 2026](https://arxiv.org/html/2606.10302v1) | Specification-level conditioning and transmission of injected diversity to output across general generation tasks. | Separating explicit names from held-fixed relations and measuring target-action yield. Supplying structured semantic content is not by itself novel. |
| [Zhang et al., Verbalized Sampling, July 2026 revision](https://arxiv.org/abs/2510.01171) | Training-free prompting of a response distribution to increase diversity. | No direct superiority claim: it is not an arm in this narrow study. It is a relevant later practical comparator. |

The review searched for current cue/label/relational-analogy and creativity work through the study date, including August/September 2026 queries. The most directly relevant newer sources located were the June diversity-injection framework and July Verbalized Sampling revision. Absence of another exact design in this targeted search is not evidence of universal novelty.

The `cards.json` source URLs separately document donor facts. They support the source relation, not the feasibility of a proposed target intervention. Experimental XR labels are intentionally incongruent and must not be displayed as factual source attributions. The report and interface should distinguish a real donor fact, an authored abstraction, a candidate target move, and an observed evaluation result.

Appropriate framing: **“We test what a domain name contributes after a relation is already supplied.”** Inappropriate framing includes claims to have created a synthetic brain network, unlocked identifiable training examples, proven a general creativity improvement, or invented externally supplied random concepts.
